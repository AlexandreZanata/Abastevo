# Home hero artwork

Generated with built-in ImageGen for the 2026-10-06 user-requested Home redesign.
The supplied Home mockup was a composition reference; the existing abastevo
logo supplied the blue/emerald palette. No generated logo replaces the original.

[Exact generation prompt](prompt.txt). The final runtime asset is
[`home_community_hero.webp`](../../../app/src/main/res/drawable-nodpi/home_community_hero.webp):
1672 × 941, 58,758 bytes. The generated PNG was encoded as WebP quality 86
without resizing, cropping, compositing or other visual edits. The original
generated PNG remains in the default Codex image-generation cache.

Runtime asset SHA-256:
`9f5ec70147752a9f4ac531ed919b2c5576255331178901091a0475b4448a7b4c`.

The artwork contains no UI, slogans, station names/prices, people, contributor
photos or source/trust claims. Title, action and brand mark are native UI
overlays; text localizes and scales without being baked into the photograph.
The exact pre-existing Android logo export is copied to `ic_abastevo_logo.xml`
with byte-for-byte geometry/gradient preservation. Launcher icons are unchanged.
