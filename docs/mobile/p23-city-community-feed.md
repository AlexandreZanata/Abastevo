## Behavior contract recorded before implementation

- B-BR-C07: anonymous city activity reads require the canonical seven-digit IBGE municipality and UF. Only active stations in that exact city are included. This is a logical city boundary inside the existing modular monolith, not a tenant or another service.
- B-BR-C08: feed cards represent current AVAILABLE community projections, not unvalidated submissions or official substitutes. Expiry is checked at read time independently of the worker. Source, fuel, exact integer BRL price, unit, STANDARD sale condition and update dates remain explicit; expiry stays explicit in the protocol and is enforced by server and client. No contributor identity, private coordinates, evidence/storage URL or image is public.
- B-BR-C09: recent order is descending anchor time with station UUID tie-break; cheapest order is integer amount ascending then station UUID. One selected fuel and its canonical unit are mandatory; only STANDARD/ STANDARD qualifier prices are compared. HMAC cursors bind city, fuel, order and page size; refresh replaces the first page, pagination is bounded. Concurrent projection changes can move rows between live pages; the client deduplicates and resets pagination on refresh.
- B-BR-C10: automatic updates use a 15-second foreground refresh, cancelled when the screen is stopped; no background GPS, notification permission or account is necessary. This is near-real-time refresh after existing validation/consensus processing, not an instantaneous submission guarantee. Failed refresh retains same-city cards with an explicit error/stale indication; changing city/fuel/order clears unrelated data. Expired cards disappear locally too.
- BUC-C06: GIVEN a preferred city, WHEN opening Community, THEN show that city's selected-fuel feed and a city selector, contribution entry, recent/cheapest filters and dated community cards. No data shows a useful empty state, never fabricated people or prices. Contribution enters existing station selection; card detail opens the canonical station profile. Rules remain accessible.
- BUC-C07: GIVEN foreground feed, WHEN a validated projection changes, THEN the newest page is automatically refreshed without duplicate cards; while browsing older pages, new updates are offered through an explicit refresh action to preserve scroll position. WHEN leaving the screen, THEN stop refresh; WHEN city changes, THEN cancel old work and load the new scope.

## Owned SQL boundary

Community owns the feed query and its generated package. It reads only directory_stations.id/display_name/municipality_code/state/status (canonical public station fields) to scope the existing community projection; it never imports the directory module or its generated package. These schema migrations are already explicitly listed in the community sqlc stanza. The read-only join is additive, parameterized and indexed; it does not change either module's write ownership. Directory's existing municipality index is reused. A rebuildable partial projection index supports each feed order. No new runtime dependency.
