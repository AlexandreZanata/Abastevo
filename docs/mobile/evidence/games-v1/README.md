# Offline Games emulator captures

Synthetic UI captured on 2026-10-11 using Compose PixelCopy from the actual
API 26 emulator, not mockups. Wi-Fi and mobile data disabled. Games test storage
is isolated from account data. Images are original PNG captures, without editing.

- [Portuguese dark selector](selector-dark-pt.png): scrollable illustrated cards.
- [Fuel Flight](flight-dark-pt.png): pumps, fuel, impulse feedback and controls.
- [Fuel Run](run-dark-pt.png): lane obstacles and directional/action controls.
- [Landscape Run](landscape-run.png): stable native stage and readable sidebar.
- [Landscape 2x text](landscape-font2.png): tutorial scrolled to its start action.

Portrait captures are 1080×1731; landscape captures are 1794×1017, excluding
system bars. The selector and 2x-font tutorial are scrollable; each image shows
the current viewport. See [test evidence](../../games-polish-emulator.md) for
source fingerprint, commands, acceptance limits and unresolved integration gate.
