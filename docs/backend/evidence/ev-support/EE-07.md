## Limits

- This unit stores verified batches only. No publication, reads,
  jobs, linking or app. Batches are immutable once stored;
  withdrawal (if ever needed) deletes the batch with cascade,
  never mutates rows.
- Directory `station_id` stays null on every row: linking places to
  stations requires reviewed evidence (future unit), never
  inferred here. The FK exists for that future, restricted on
  delete.
- Invalid units (bad enums, out-of-bounds, orphan groups) refuse at
  the CHECK/FK level with rollback; cryptographic invalidity was
  already refused by the bridge before staging.
- No device, no production, no deploy and no release acceptance is
  claimed.
