Before behavior: hosted vehicles carry explicit propulsion with
optional battery, reusing tank capacity without new tables (JSONB
payloads, no DDL). BEV requires battery without tank; PHEV requires
one battery and one tank; HEV and legacy ICE carry tank without
battery; unknown propulsion refuses; battery is never backfilled.
Older clients omitting energy fields merge (stored values survive)
instead of erasing; explicit values always win; revision conflicts
guard races. Recovery: disable new energy edits, retain all
existing vehicles/history.

## Limits

- Energy fields are optional pointers for backward compat. HEV
  tracks tank only (no external-charge data model yet); explicit
  null clears nothing (nil preserves); deleting battery requires
  vehicle recreate (documented, rare).
- Merge reads outside the write transaction; concurrent modification
  between merge and commit fails with conflict (safe) rather than
  merging twice. No lost-update window beyond the existing revision
  protocol.
- Unknown propulsion, BEV-with-tank, PHEV-without-battery and
  HEV-with-battery refuse; legacy premium-fuel mapping intact.
- No device, no production, no deploy and no release acceptance is
  claimed.
