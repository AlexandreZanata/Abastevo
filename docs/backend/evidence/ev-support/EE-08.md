revisions without downloading; merge/split review flags added, missing
and changed places without auto-linking. Imports and schedules default
off with explicit config gates; failures retain the last accepted
public state. Recovery: imports/schedules off, retain last state.

## Limits

- Jobs are implemented and unit-tested; queue/dispatcher
  registration and schedules stay off until import enablement
  (explicitly default-off). Manual `Runner` execution and tests
  prove the mechanics; production queue wiring is a future unit.
- Discovery reports index reachability only; it never downloads
  snapshots, keys or bulk data (fetching needs separate review).
- Merge/split flags are advisory; no auto-link, auto-close or
  auto-bind occurs. Corrections create new batches; replays return
  existing ones.
- OSM adapter explicitly out of scope (separate suffixed task after
  rights/need admission; no commercial candidates implemented).
- No device, no production, no deploy and no release acceptance is
  claimed.
