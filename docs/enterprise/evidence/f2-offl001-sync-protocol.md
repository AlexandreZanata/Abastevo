## Tested contract

[Task217](https://github.com/AlexandreZanata/Abastevo/issues/217) remains open
until protected integration. Implemented pure Go/Kotlin strict canonical JSON,
full immutable operation identity, independently supplied source binding, copied
batch candidates with captured trusted limits, exact-origin validation and
ACK parsing which requires the original operation. Normalized sets reject
identity duplicates; normal payload arrays preserve order. Diagnostic formatting,
JSON and structured logging are redacted; explicit accessors defensively copy.

The source includes no feature handler, queue, receipt database or active route.
Batch candidates are not admitted operations. OFFL-002 must preflight correlation
and source proof for the entire body before any receipt/effect, then execute
independent per-operation transactions. Reserved result codes do not implement
late intake, plan/grace policy or source authorization.

OpenAPI has matching component-only DTOs. Offline specification §10.1 is now
normative. Exact integer lexical values, duplicate decoded keys, strict Unicode,
raw/canonical byte budgets, depth, digest correctness and independent source
binding are codec obligations which structural JSON Schema cannot prove.
Generic declaration time permits the existing OrgTime minimum; final server
receipt explicitly excludes that sentinel.
