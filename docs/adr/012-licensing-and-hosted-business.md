# ADR-012: Preserve MIT and separate hosted convenience from community trust

Status: **MIT preservation adopted; future license undecided**. Date: 2026-09-28. Scope: planned platform; implementation evidence required by roadmap gates.

## Context

Upstream code and outside contributions have MIT provenance. Commercial aspirations do not authorize silent relicensing.

## Decision

Keep existing license/notices; new MVP work stays MIT absent explicit future decision. Compare MIT/Apache client/AGPL backend with ownership/dependency review before any change. Name Postô provisional. Optional hosted services later; payment never changes trust.

## Alternatives

Immediate relicensing/rebranding; paid contribution credibility; paywall current offline capabilities.

## Consequences

No removal of rights from historical MIT versions. DCO recommended for new contributions; CLA only for demonstrated need. Trademark clearance and legal review precede public rebranding.

Use the owning tasks in [ROADMAP](../../ROADMAP.md), specifications in [docs index](../README.md) and [decision log](../planning/DECISIONS.md). Record tested policy/tool versions before marking a release gate complete.
