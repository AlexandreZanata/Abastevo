# Enterprise source admission register

Status: FROZEN FOR LOCAL CONSTRUCTION; public-release gates remain explicit.
Date: 2026-10-24. Task: ESP-01.
Owner: [enterprise data/static portal plan](../planning/ENTERPRISE_DATA_STATIC_PORTAL_PLAN.md#esp-01--admit-source-profiles-rights-and-public-fields).
Rules: [B-BR-ESP-02–09/16](ENTERPRISE_DATA_STATIC_PORTAL_CONTRACT.md).

This register freezes the fields, keys, clocks, coverage, retention, correction
windows and quotas used by the ESP export/portal. It does not enable a source,
schedule, import, public route or deployment. Unknown rights, schemas or coverage
are recorded as unknown, never inferred from a page label or an existing parser.

## Rights policy

The ANP site footer declares `CC BY-ND 3.0` for **site content**. That footer is
not a dataset license and does not authorize derived public data products. Dataset
rights come only from the dataset metadata or an explicit ANP statement:

| Source | Declared dataset license | Public derived release |
| --- | --- | --- |
| S-ESP-01 registry | none found; metadata PDF has no text layer | `RIGHTS_PENDING` |
| S-ESP-02 prices | none found in the historical/series metadata | `RIGHTS_PENDING` |
| S-ESP-03 enforcement | CC BY, CC0, ODbL or PDDL (metadata menu) | `ADMITTED` under CC BY attribution, runtime blocked |
| S-ESP-04 fines | CC BY (metadata) | event-level `ADMITTED` under CC BY attribution; station links only when `linked` |
| S-ESP-05 PMQC | none found in the October 2026 metadata | `RIGHTS_PENDING` |
| S-ESP-06 registry API | not inspected/admitted | `NOT_ADMITTED` |

`RIGHTS_PENDING` means the profiles may feed local implementation and internal
analysis, but the public static release must not publish their rows, station
pages, rankings or downloads until the maintainer records a compatible license
or written permission. This blocks the price/registry/PMQC slices of ESP-18, not
the unrelated official-record slices whose declared license and runtime gates
pass. No profile is enabled by this register.

## Three representations

- **Original artifact:** fetched bytes, URL, media type, byte count and SHA-256,
  private temporary storage, never under the public root or in Git.
- **Normalized fact:** module-owned revision/row with source URL/checksum,
  parser/profile version and source clock.
- **Derived public output:** allowlisted JSON/HTML/CSV generated by ESP from a
  pinned manifest; no raw document, private field or internal note.

## Public field policy (all profiles)

Allowed: public station UUID and full CNPJ (14 digits, leading zeros/letters
preserved), public business name/address/municipality/UF, reviewed coordinates
only, fuel/product, exact source unit, condition when known, milli-BRL amount,
source dates, source URL/checksum, revision/edition identity, and the applicable
clock. Excluded everywhere: CPF, private account/owner data, contributor GPS,
user photos, internal notes, raw source paths, credentials and unverified
coordinates. Unknown values stay missing; they are never zero, average or a
nearby station's value.

## S-ESP-02 — ANP weekly prices and historical series (reuse Official)

- **Observed 2026-10-24:** recent page `200 text/html`, 446,356 bytes; updated
  2026-10-23 16:29. We use the station detail (`revendas_lpc_*.xlsx`) and retain
  the municipal summary (`resumo_semanal_lpc_*.xlsx`) only as official summary,
  never as station facts.
- **Current naming gap:** the newest listed week uses
  `revendas_lpc_2026_10_11-2026_10_17.xlsx`; older weeks use
  `revendas_lpc_2026-10-04_2026-10-10.xlsx`. The existing discovery builds only
  the second shape (`%s_%s` with ISO dates), so it cannot discover the newest
  week. ESP-02 must accept the observed variants without inventing a period.
- **Historical series:** page `200 text/html`, 328,336 bytes; updated
  2026-10-20. Files are semester ZIPs such as `ca-2026-01.zip`, not the single
  CSV described in `docs/data-sources.md`. Metadata PDF 191,035 bytes SHA-256
  `cfe58226…2b8350`, updated 2026-03-06, declares CSV format, weekly/monthly/
  semester cadence and fields; it declares no license.
- **Ingestion:** existing Official XLSX parser, staged revisions, review gate,
  import jobs and read port. No second parser/import path.
- **Native key/dedupe:** import identity = source URL + source SHA-256 + parser
  version; observations are keyed by station, product, unit and collection date
  inside one published revision. Supersession retains corrections.
- **Public fields:** UUID, CNPJ, product, unit, `condition.kind`, amount in
  milli-BRL, currency BRL, collected date, survey start/end, revision ID,
  supersession reference, source URL/checksum, parser version and Abastevo
  publication time. Municipal summaries keep their official product/period/unit
  and are labeled as ANP summary statistics.
- **Excluded:** raw workbook text from HTML pages; municipal mean is never
  attached to a station; no national mean is derived by averaging municipal means.
- **Clocks:** collection date, survey week, source page update, last successful
  check and Abastevo publication are separate. Stored coverage is measured; a new
  build does not refresh source age.
- **Discovery/validators:** scheduled run covers the current and previous survey
  week; the source is not assumed to expose a reliable ETag, so each file is
  content-hashed and the hash is the dedupe identity. A 404 means "not
  published", not "no prices". An operator correction sweep may request up to
  five recent weeks in the job payload; older corrections use a controlled
  backfill.
- **Correction window:** current and previous week on the schedule; a bounded
  correction sweep may reach the previous four weeks, then a documented
  controlled backfill. This is an Abastevo operating policy, not an ANP
  guarantee.
- **Quotas/retention:** scheduled run probes two weeks × two file kinds; a
  correction sweep is capped at five weeks; raw files private and removed after
  publication. Backfill is one archive/member per run with byte/row caps.
- **Coverage:** station-level survey subset, not every station or every day.
  Rankings mean "prices found in the identified survey period", with counts,
  ties and exclusions.
- **Status:** `ingest=EXISTING`, `public_release=RIGHTS_PENDING`.

## Operational limits shared by the ESP pipeline

- No visitor request triggers a fetch, import or build. Ingestion/build runs are
  operator-scheduled or invoked by the owned worker only.
- Each source run has one bounded slot; general safety/API work keeps its own
  budget. Existing FQ source leases and default-off switches are reused.
- Redirects stay on the admitted host/prefix; no query/fragment/port tricks;
  response bytes, archive entries, member size, rows, time and concurrency are
  bounded. 429/5xx backs off with jitter; a failed/partial/unknown layout keeps
  the last accepted publication.
- Raw source artifacts, temp files and prepared quarantine samples stay outside
  Git and the public root. Logs contain no CPF, precise contributor position,
  private document or full source path.
- Corrections rebuild every affected page, index, ranking and download; withdrawn
  records cannot return through a rollback to an older release.

## Change control

A profile change (URL pattern, schema, key, clock, field allowlist, rights,
correction window or quota) requires a new register revision and affected tests.
A source whose rights or live contract is unknown stays `RIGHTS_PENDING` or
`NOT_ADMITTED`; it does not inherit admission from a sibling ANP dataset.
