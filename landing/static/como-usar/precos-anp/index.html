Consultar a tabela ANP

Como ler média, mínimo, máximo e contagem de postos pesquisados na tabela semanal ANP do aplicativo abastevo, com a semana datada. Lição TU05 · 3 passos · somente leitura.

  1. Passo 1: Etanol, preço médio R$ 3,96

    Toque no cartão do combustível para ver os postos.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Abre a lista de postos daquele combustível.

    Se não funcionar: Volte para ler outra média.

  2. Passo 2: Média: R$ 3,96

    Leia média, mínimo e máximo com contagem de postos.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Média com mínimo, máximo e 7 postos pesquisados.

    Se não funcionar: Valores são da semana; troque a semana para comparar.

  3. Passo 3: Semana de pesquisa

    Confira a semana de pesquisa no topo.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Semana datada, nunca preço vivo na bomba.

    Se não funcionar: Semana antiga indica dados desatualizados.
