Minhas contribuições

Como acompanhar envios, fila e cancelamentos somente neste aparelho na tela Minhas contribuições do aplicativo abastevo. Lição TU17 · 2 passos · somente leitura.

  1. Passo 1: Colaborar com preço

    Comece uma colaboração pelo botão.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Abre o fluxo de captura com posto exigido.

    Se não funcionar: Sem posto elegível, o obturador desabilita.

  2. Passo 2: Nenhuma contribuição neste dispositivo ainda.

    Entenda que o extrato é só deste aparelho.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Vazio declarado, nada público.

    Se não funcionar: Envios aparecem aqui após a fila.
