Trocar ou baixar uma semana

Como trocar a semana de pesquisa, consultar o arquivo de semanas e voltar à mais recente no aplicativo abastevo. Lição TU06 · 3 passos · somente leitura.

  1. Passo 1: 4–10 out. 2026 · Atual

    Toque no seletor de semana no topo.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Abre a lista de semanas arquivadas.

    Se não funcionar: Feche e tente de novo.

  2. Passo 2: Usar semana mais recente

    Volte à semana mais recente quando quiser.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Restaura a semana atual datada.

    Se não funcionar: Escolha um arquivo listado para comparar.

  3. Passo 3: 4–10 out. 2026

    Confira a semana marcada como atual.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Semana atual indicada com data de atualização.

    Se não funcionar: Arquivo sem dados exibe aviso honesto.
