Ler o histórico

Como ler o gráfico de tendência de três semanas e os valores semanais do histórico de preços ANP no aplicativo abastevo. Lição TU07 · 3 passos · somente leitura.

  1. Passo 1: Gasolina comum

    Escolha o combustível da série.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Gráfico e valores filtram para o combustível.

    Se não funcionar: Troque o chip para outra série.

  2. Passo 2: Gráfico de tendência de preços

    Leia a tendência de 3 semanas no gráfico.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Barras com 6,83, 6,88 e 6,94 nas semanas.

    Se não funcionar: Poucas semanas indicam série curta.

  3. Passo 3: 4–10 out. 2026

    Confira os valores por semana abaixo do gráfico.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Cada semana com seu valor datado.

    Se não funcionar: Semana sem coleta não aparece.
