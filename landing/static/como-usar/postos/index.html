Encontrar e navegar até um posto

Como buscar postos por nome, ordenar por menor preço e abrir detalhes com dados ANP datados no aplicativo abastevo. Lição TU08 · 5 passos · somente leitura.

  1. Passo 1: Buscar por nome do posto

    Busque pelo nome do posto.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Filtra a lista sem sair da tela.

    Se não funcionar: Limpe a busca para ver todos.

  2. Passo 2: Menor preço primeiro

    Ordene por menor preço primeiro.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Lista reordena pelos valores ANP datados.

    Se não funcionar: Ordem por distância exige localização.

  3. Passo 3: Cartão do posto

    Toque no cartão para ver detalhes e navegar.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Abre identidade, preços por fonte e botão Ir.

    Se não funcionar: Sem preço comunitário, vale a referência ANP.

  4. Passo 4: Buscar por nome do posto

    Busque um nome inexistente para ver o erro honesto.

    Estado: Error state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Nada por aqui: nenhum posto corresponde, sem travar.

    Se não funcionar: Limpe a busca; a lista volta sozinha.

  5. Passo 5: Mais barato perto de mim

    Use Mais barato perto de mim com a permissão existente.

    Estado: Error state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Sem posto próximo, aviso honesto; verifique conexão e localização.

    Se não funcionar: A lista por preço segue disponível sem localização.
