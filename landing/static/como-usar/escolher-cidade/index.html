Escolher cidade

Como escolher a cidade no aplicativo abastevo: Minha cidade, busca de estado e lista de municípios, com capturas reais. Lição TU02 · 4 passos · somente leitura: estes passos nunca criam conta, votam ou enviam dados.

  1. Passo 1: Minha cidade

    No Explorar, toque em Minha cidade.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Abre Selecionar localização com a cidade atual.

    Se não funcionar: Volte com o botão do sistema.

  2. Passo 2: Buscar estado

    Busque o estado ou toque na linha do estado.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Mostra a lista de estados com a cidade atual indicada.

    Se não funcionar: Limpe a busca para ver todos os estados.

  3. Passo 3: Buscar município

    Dentro do estado, busque o município na lista agrupada.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Mostra os municípios do estado em grupos alfabéticos.

    Se não funcionar: Volte para trocar de estado sem alterar a cidade.

  4. Passo 4: SORRISO, MT

    Confirme a cidade no Explorar com a semana ativa.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Explorar exibe SORRISO, MT com a semana de pesquisa atual.

    Se não funcionar: Reabra Minha cidade para corrigir.
