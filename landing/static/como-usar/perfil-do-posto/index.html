Consultar perfil do posto

Como conferir identidade, endereço e ações de um posto no abastevo. Lição TU23 · 3 passos · somente leitura.

  1. Passo 1: JABER COMERCIO DE COMBUSTIVEIS LTDA

    Confira razão social e bandeira.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Identidade pública do cadastro ANP.

    Se não funcionar: Nome divergente indica cadastro desatualizado.

  2. Passo 2: Atualizar preço

    Use Ir para navegar ou Atualizar preço.

    Estado: Visible state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Entradas de ação sem sair do perfil.

    Se não funcionar: Atualizar exige conta e posto elegível.

  3. Passo 3: RUA ALENCAR BORTOLANZA

    Endereço público orienta a chegada.

    Estado: Result state · App 3.1.0-debug · captura 2026-10-11

    Resultado esperado: Endereço do cadastro, nunca GPS de pessoa.

    Se não funcionar: Endereço divergente: confira na rua.
